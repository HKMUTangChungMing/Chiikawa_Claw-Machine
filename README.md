# Chiikawa_Claw-Machine
Recently I made a Window app with Claude AI. It is only for fun. 
<img width="1683" height="1271" alt="未命名" src="https://github.com/user-attachments/assets/2796873e-2968-4892-894a-85bec87d8810" />

After entering 666 to unlock, this claw machine allows you to adjust the grip tightness or force, and you can also place any type of plush toy on it.
當輸入666解鎖後。這個夾公仔機可以調教夾的鬆緊度或力度，此外，它也可以任意放置公仔。

Remember to press C to enter the token.
記得按C鍵輸入代幣。

Go ahead and savor the therapeutic joy of clawing those plushies!!!!
好好享受夾公仔的自癒快感吧!!!!
